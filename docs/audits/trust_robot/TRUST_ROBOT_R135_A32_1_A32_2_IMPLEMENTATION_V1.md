provided quarantine directory.

oversized artifacts and mismatched hashes are rejected.

A30-4 fail-closed evidence-intake preflight.

agreement with the submitted digest.

capture applicability, witness independence, clock
accuracy, metric calibration or pose reference validity.

A dry-run using synthetic bytes exercises the interface.
No physical artifact is admitted.
